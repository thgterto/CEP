## 2026-05-19 - Avoiding Committing Binary Artifacts During Refactoring
**Learning:** When running frontend verification scripts (like Playwright with `page.screenshot()`), large binary artifacts (e.g., `verification.png`) can be generated and accidentally staged or committed, cluttering version control.
**Action:** Always perform a workspace cleanup and check `git status` to ensure generated scratchpad scripts, logs, and binary files are explicitly removed before staging changes and submitting.

## 2026-05-19 - Optimizing I-MR calculation using Single-Pass Loop and Pre-Allocation
**Learning:** Re-iterating over dynamic arrays (`push`), using `[0, ...ranges]`, and making multiple calls to `SPC.mean` in tight data processing loops (e.g., `computeIMR`) causes severe memory allocation overhead and >4x slowdown. Furthermore, spreading large arrays can hit V8's call stack limit and trigger fatal `RangeError` exceptions.
**Action:** When implementing statistical chart calculations over potentially large numeric datasets, utilize a single-pass `for` loop, inline mathematical functions (like `Math.abs`), and statically pre-allocate arrays (`new Array(len)`). Always guard against empty array and single-element bounds with explicit early returns rather than relying on implicit out-of-bounds `NaN` generation to prevent index alignment issues and invalid length errors.
