## 2026-05-13 - Avoid committing test artifacts and verify Git status before cleanups
**Learning:** Temporary ad-hoc benchmark scripts (`benchmark_xbar.js`), test output images (`verification.png`), and dynamically generated logs (`server.log`) should not be committed to the repository. Committing these files introduces unnecessary bloat to the Git history and litters the codebase with transient artifacts. Additionally, blindly running file deletion commands like `rm server.log` without checking `git status` first can inadvertently stage tracked files for deletion if they were already part of the repository.
**Action:** Always run `git status` to verify the state of modified and untracked files before staging commits. Explicitly remove all temporary test scripts, output files, and logs using `rm` (and `git restore --staged` if accidentally staged) prior to creating a pull request.
