## 2026-05-19 - Avoiding Committing Binary Artifacts During Refactoring
**Learning:** When running frontend verification scripts (like Playwright with `page.screenshot()`), large binary artifacts (e.g., `verification.png`) can be generated and accidentally staged or committed, cluttering version control.
**Action:** Always perform a workspace cleanup and check `git status` to ensure generated scratchpad scripts, logs, and binary files are explicitly removed before staging changes and submitting.
## 2026-05-19 - Pre-Allocating Array Spreads for IMR
**Learning:** In SPC statistical calculations like `computeIMR`, using dynamic arrays (`push()`) followed by the spread operator `[0, ...ranges]` forces multiple memory allocations and O(N) spreads. Pre-allocating the array using `new Array(len)` and assigning values dynamically (with manual loop calculations) yields a massive 6x performance boost. However, it requires manually accounting for exact edge cases (e.g. `len === 0` and `len === 1`) to preserve implicit fallback behaviors (e.g. `NaN` and `0` values) generated by spreading empty arrays or operating on out-of-bounds indices in the baseline version.
**Action:** When replacing array map/filter/reduce/spread combinations in charting math with pre-allocated arrays, explicitly document and unit-test edge cases for empty and single-element inputs, ensuring the new behavior strictly equals `JSON.parse(JSON.stringify(baseline))` (where NaNs and undefineds align perfectly).
