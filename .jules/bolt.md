## 2024-03-12 - [Performance Optimization: Pre-allocating Arrays and Manual Indexing in CUSUM Calculation]
**Learning:** In the `computeCUSUM` function, calculating process stats involves pushing elements to an array and then shifting the initial 0 value. The `shift()` array method is inefficient, operating in $O(n)$ time since it requires re-indexing the entire array. Furthermore, the math operations use `Math.max` and `Math.min`. By avoiding `Array.prototype.push()` and `shift()` and substituting `Math.max` / `Math.min` with inline conditionals, execution speed more than doubles (e.g., ~359ms -> ~164ms for 50 iterations of 100k items).
**Action:** Always prefer explicit pre-allocated arrays (e.g. `new Array(len)`) and manual index tracking instead of `push`/`shift` for loops executed in hot paths. Use inline boolean logic to determine min / max where possible.
