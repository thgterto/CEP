## 2026-05-14 - Optimize EWMA calculation avoids redundant arrays allocations and slow math calls
**Learning:** In chart calculation functions (e.g., `computeEWMA`), avoid explicitly adding early returns for empty datasets (`len === 0`) if they unnecessarily duplicate the return payload. Instead, allow pre-allocated arrays (`new Array(len)` creating `[]`) and natural mathematical fallbacks (like `SPC.mean([])` evaluating to `NaN`) to naturally produce the correctly formatted empty chart structure.
**Action:** When replacing array allocations (like `push()`) with `new Array(len)`, rely on JavaScript's natural handling of empty arrays and `NaN` propagation instead of prematurely adding explicit `if (len === 0)` checks that duplicate code, unless strict boundary tests fail without them.
