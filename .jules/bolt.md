## 2026-05-19 - Avoiding Committing Binary Artifacts During Refactoring
**Learning:** When running frontend verification scripts (like Playwright with `page.screenshot()`), large binary artifacts (e.g., `verification.png`) can be generated and accidentally staged or committed, cluttering version control.
**Action:** Always perform a workspace cleanup and check `git status` to ensure generated scratchpad scripts, logs, and binary files are explicitly removed before staging changes and submitting.
## 2024-05-18 - Fast Array Pre-allocation and Invariant Extraction in EWMA
**Learning:** In hot statistical loops like `computeEWMA`, extracting constant, loop-invariant mathematical operations (e.g., `1 - lambda`, `lambda / (2 - lambda)`) outside the iteration, combined with replacing O(N) array `.shift()` and dynamic `.push()` calls with pre-allocated arrays, yields a >40% execution speedup. It is critical to strictly preserve iteration-dependent native operations like `Math.pow()` as-is to prevent floating-point precision drifts that fail baseline strict equality assertions.
**Action:** When optimizing loop-heavy array processing algorithms, aggressively pre-allocate arrays, extract invariant scalar math above the loop, and use discrete state tracking variables (`prevZ`) instead of array mutations. Always use strict mathematical baselining on both populated and empty (`[]`) inputs to verify precise `NaN` fallback matching.
