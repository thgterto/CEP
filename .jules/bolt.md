## 2025-02-14 - Respecting Boundaries with Corrupt Files
**Learning:** Even when a configuration file like `package.json` is corrupt (e.g., literal `\n` characters) and prevents local verification scripts from running, do not modify it without explicit instruction.
**Action:** Always ask for permission before fixing environment or configuration issues that are outside the scope of the immediate task. Work around them or use alternative verification methods if possible.
